📂 프로젝트 파일 구조 (Django home 및 static 구조)

     Django의 표준 static 파일 관리 방식에 맞추어 파일 위치를 다음과 같이 구성


soccer_game/
├── home/
│   └── templates/
│       └── index.html               <-- HTML 구조 (메인 템플릿)
└── static/
    ├── css/
    │   └── style.css                <-- 레이아웃 및 스타일 정의
    ├── js/
    │   └── game.js                  <-- Canvas 드로잉 및 경기 시뮬레이션 로직
    ├── images/
    │   └── pitch_bg.png             <-- 운동장 배경 이미지[cite: 3]
    └── data/
         └── 'user_name_file'.json    <-- 각 리그/구단별 선수 정보 및 성적 json파일 폴더

1. images폴더 구조

  1) 1부리그/ 구단마크 : 1부리그 소속의 각 구단 마크 이미지(강원,광주...등, 구단 이름의 png파일) 12개팀
            / 강원,광주...등, 각 구단이름의 폴더가 존재 12개팀 - 소속 선수 이름의 사진이 있음

  2) 2부리그/ 구단마크 : 2부리그 소속의 각 구단 마크 이미지(강원,광주...등, 구단 이름의 png파일) 17개팀
            / 경나, 김포...등, 각 구단이름의 폴더가 존재 17개팀 - 소속 선수 이름의 사진이 있음

2. data폴더 구조

  1) 1부리그/ 구단성적.josn, '구단이름_선수성적'.json과 '구단이름_선수정보'.json파일이 존재(12개 구단)

  2) 2부리그/ 구단성적.josn, '구단이름_선수성적'.json과 '구단이름_선수정보'.json파일이 존재(17개 구단)

📄 구체적으로 어떤 부분부터 진행 할 것인가?

1. HTML5 Canvas 기반 축구장 및 선수 애니메이션 기본 코드 작성

  - 화면구성 및 게임 젙체 로직 설계 단계
   
    > 축구장의 디자인 하여 백 배경 이미지로 설정. 이렇게 하므로서 선수들의 움직입 제어시 운동장을 다시 그리는 동작을 안해도 됨

    > 운농장 영역은 캔버스를 이용하여 순수 선수들의 운동제어 함수와 경기 규직 적용 함수의 적용 영역으로만 설정한다.

2. K리그 JSON 데이터 파싱 및 Django 모델/API 구축

  - 선수 상세 정보 및 인터랙션: 락커룸의 선수 카드를 클릭했을 때 상세 스탯(생년월일, 키, 몸무게 등)을 팝업이나 패널로 확인할 수 있는 기능

💡 게임 고도화 활용 방안이 성적 데이터([구단이름]_선수성적.json)를 앞서 구현한 선수 상세 정보 및 매치 엔진과 연동

   >> 다음과 같은 고도화가 가능합니다.

    - 선수 카드 모달 확장: 락커룸에서 선수를 클릭했을 때 뜨는 팝업 모달에 실제 득점, 도움, 출전 시간, 패스 성공률 등의 성적 지표를 함께 보여줄 수 있습니다.

    - 매치 엔진 능력치 반영: 득점이나 슈팅 수, 패스 성공률 등의 실제 데이터를 바탕으로 가상 경기 시뮬레이션 시 선수별 능력치(결정력, 패스 정확도 등)에 실질적인 

      가중치를 부여할 수 있습니다


3. 선수 능력치 기반 경기 시뮬레이션 엔진 로직 설계

  - 매치 엔진 고도화: 선수들의 실제 능력치(키, 체중 등)나 선택한 전술(공격형, 점유율 등)에 따라 경기 중 움직임이나 득점 확률에 실질적인 영향이 미치도록 로직 개선

  - 실시간 경기 이벤트 및 스코어 시스템: 경기 시간(00:00) 흐름에 맞춰 슈팅, 유효슈팅, 파울, 득점 등의 실시간 로그가 자동으로 발생하고 스코어보드에 반영되는 기능
