# 여기서 시작하세요

[전체 공부 안내 열기](learning/README.md)

1. `manage.py`가 있는 이 폴더에서 기존 가상환경을 사용합니다.
2. `python manage.py check`로 연결을 확인합니다.
3. `python manage.py runserver`로 화면을 엽니다.
4. `learning/README.md`의 순서대로 하나의 화면부터 따라갑니다.
5. 수정 위치는 `learning/07_수정위치찾기.md`, 모든 파일 안내는 `learning/01_전체파일지도.md`에 있습니다.

기존 원본 폴더에 곧바로 덮어쓰지 않고 별도 폴더에서 확인하는 전체 프로젝트입니다. 데이터와 가중치는 그대로이며, HTML에서 분리한 정적 파일도 함께 포함돼 있습니다.
