# 코드 읽기에 필요한 문법

- **parameter, 매개변수**: 함수가 받는 입력 이름. `per90(value, minutes)`의 두 이름입니다.
- **return, 반환**: 함수를 끝내고 결과를 호출한 곳으로 보냅니다.
- **dictionary, 사전**: 키와 값의 묶음. `result['team_id']`는 이름표의 값을 꺼냅니다.
- **list, 목록**: 순서가 있는 여러 값. `ranking[:3]`은 앞 세 개입니다.
- **tuple, 튜플**: 고정된 순서의 묶음. `GROUPS` 한 행의 네 칸은 뜻이 다릅니다.
- **None, 없음**: 숫자 0과 다릅니다. 기록 부재를 0으로 채우면 점수가 달라질 수 있습니다.
- **lambda, 짧은 함수**: `lambda stats, virtual: ...`는 두 입력을 받아 식의 값을 반환합니다.
- **comprehension, 내포식**: 반복해서 목록/사전을 만드는 짧은 표현. 어려운 핵심 계산은 단계별 반복문으로 풀었습니다.
- **class, 클래스**: 관련 상태와 작업을 묶는 설계. `Normalizer`는 최저/최고/평균을 가지고 정규화를 합니다.
- **self**: 지금 작업하는 객체 자신입니다. `self.mean`은 그 객체에 보관한 평균입니다.
- **decorator, 장식자**: `@require_POST`처럼 함수 호출 조건을 감쌉니다. 삭제하면 허용 요청이 달라집니다.
- **ORM**: Python 표현으로 DB를 조회하는 도구. `filter()`는 거르고 `select_related()`는 관계 데이터를 함께 읽습니다.
- **transaction, 트랜잭션**: 여러 저장을 한 묶음으로 처리합니다. 중간 실패 시 일부만 반영되는 것을 막습니다.
- **cache, 임시 보관**: 같은 자료를 매번 다시 읽지 않도록 잠깐 보관합니다. 값을 바꾸면 캐시 갱신도 확인합니다.
- **scope, 이름이 보이는 범위**: 함수 안의 이름과 바깥 이름은 다를 수 있습니다. 이름을 바꿀 때 호출 위치도 확인합니다.
- **DOM**: 브라우저가 HTML을 다룰 수 있게 만든 객체 구조입니다.
- **event, 사건**: 클릭·선택 변경·시간 경과 같은 동작입니다.
- **fetch**: JavaScript에서 서버로 요청합니다. `await`는 결과를 기다리는 표현입니다.
- **JSON**: 사전/목록 같은 데이터를 주고받는 글자 형식입니다. 문자열과 실제 객체는 구분합니다.
- **localStorage**: 해당 브라우저에 저장하는 개인 설정입니다. 서버 DB가 아닙니다.
- **Canvas**: JavaScript로 그림을 그리는 화면입니다. 게임과 GPS의 캔버스가 같은 엔진이라는 뜻은 아닙니다.
- **CSS selector, 선택자**: 어떤 HTML에 모양을 적용할지 정합니다. `.player-card`는 해당 class, `#pitch`는 해당 id입니다.
- **AST, 구문 구조**: 코드를 글자 모양이 아닌 문법 구조로 읽은 결과입니다. 서식 정리에서 구조가 유지됐는지 비교했습니다.
