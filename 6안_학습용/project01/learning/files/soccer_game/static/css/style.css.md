## 이 파일을 읽을 때

1. 입력을 어디서 받는지 찾습니다.

2. 값을 바꾸는 계산과 DB를 읽거나 쓰는 부분을 구분합니다.

3. 마지막 `return` 또는 화면/이벤트 연결을 확인합니다.



## 처음 읽는 순서

1. 색상·폰트와 공통 선택자

2. 화면 영역별 배치

3. 버튼·카드·표 등 부품

4. `@media`: 휴대폰 등 화면 폭별 덮어쓰기

## 수정 기준

같은 선택자가 여러 번 나오면 보통 뒤쪽 규칙이 영향을 줍니다. 규칙을 가나다순으로 재배치하지 않았습니다. 원래 선택자·값·미디어 조건·순서를 보존하고 들여쓰기와 설명을 정리했습니다.
